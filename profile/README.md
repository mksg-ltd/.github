## 🎨 Featured Projects

### [Wallflow Theme](https://github.com/mksg-ltd/vscode-wallflow-theme)
A dynamic VS Code theme that automatically updates to match your wallpaper colors. Experience a seamless, personalized coding environment that adapts to your desktop aesthetics.

**Key Features:**
- Real-time color updates when your wallpaper changes
- Two variants: borderless and bordered
- Works automatically with wallflow - no manual configuration needed
